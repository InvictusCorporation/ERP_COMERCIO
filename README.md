# Invictus ERP Comercial

Plataforma modular da Invictus Systems para comércio, estivas, mercados e redes de supermercados. Experiência web responsiva e PDV mobile no mesmo produto, com evolução para SaaS e white-label.

## Instalação

Ainda não se aplica: não há `package.json`, migrações ou comandos de execução. A entrega 01.1 criará o workspace e fixará versões compatíveis. Não executar comandos de instalação de projetos vizinhos.

Tecnologia proposta: TypeScript, Next.js para web, NestJS para API e PostgreSQL para persistência. Desenvolvimento local; implantação em produção depende de autorização expressa.
